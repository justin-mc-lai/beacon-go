# 示例：需求模糊，先问再规划

**用户说**：「做个更好用的后台」

**mode_id**：`pln-brainstorm`

**做法**
1. 只问一个问题（带推荐）：
   `beacon truth ask --feature admin --question "你说的更好用，是指操作步骤更少，还是信息更全？" --recommend "操作步骤更少"`
2. 等回答，再问第二个；一次只问一个
3. 问题清空后：`beacon truth intent ...` 记录用户原话、目标、非目标、约束

**产出**：一份意图快照（原话 + 目标 + 非目标 + 约束）

**不要做**：一口气问五个问题；替用户回答；直接给方案
