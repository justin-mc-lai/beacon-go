# Beacon Agent 极简浅色桌面工作台设计方案 (OpenMuse 风格)

> 实施后记（2026-10-28）：前端一度收敛为 `internal/webui/index.html`。
> 2026-10-28 晚的「只保留桌面端」决定（`change-desktop-only.md`）随后删除了该中间层，
> 唯一来源回到 `desktop/frontend/index.html`；本文路径仅作历史记录。

> **模式**: `pln-review` / `pln-program`  
> **设计基调**: **纯白/浅灰高亮极简风 (OpenMuse Light)** + **桌面原生应用 (Desktop Native)** + **内敛复杂度的生成式卡片**  
> **核心哲学**: **“把复杂的 FSM 状态机、多 Agent 握手、Truth/Tests 规约为两张极简卡片：Plan 规划方案卡 ➔ Goal 确认与执行卡”**

## 一、视觉与色彩体系规范 (OpenMuse Light Palette)

彻底告别沉重压抑的黑灰深色工控风，全面倒向 Apple / OpenMuse 经典的**高留白、轻阴影、呼吸感浅色设计**：

| 色彩层级 | 代号 / 类名 | HEX 色值 | 应用场景 |
|---|---|---|---|
| **应用背景 (App Canvas)** | `bg-slate-50` | `#F8FAFC` | 桌面原生视窗底色，极简干净 |
| **卡片与容器 (Card Surface)**| `bg-white` | `#FFFFFF` | 生成式卡片、输入框、设置弹窗底色 |
| **浅灰描边 (Border Subtle)** | `border-slate-200` | `#E2E8F0` | 1px 超细自然描边，绝无粗重框线 |
| **主标题与正文 (Text Main)** | `text-slate-900` | `#0F172A` | 高对比度纯净黑，字迹锐利 |
| **次要引导文本 (Text Muted)** | `text-slate-500` | `#64748B` | 解释说明、时间戳、快捷键提示 |
| **品牌与交互主色 (Primary)** | `indigo-accent` | `#4F46E5` | 参谋长徽章、确认按钮、活跃状态 |
| **成功与验资 (Verified)** | `emerald-500` | `#10B981` | 机器测试通过 (Exit 0)、验收交付 |
| **提示与边界 (Warning)** | `amber-500` | `#F59E0B` | 隐性边界、未冻结改动提示 |

## 三、设置中心：极简弹窗设计 (Settings Modal)

点击右上角 **[⚙️ 设置]** 呼出纯白悬浮弹窗，涵盖你要求的全部能力：

### 1. 语言切换 (Language)
* **选项**：`简体中文 (zh-CN)` / `English (en-US)`（一键无刷新即时切换界面所有文案）。

### 2. BYOK 多提供商配置 (Bring Your Own Key)
* **默认本地网关**：`OpenCodex 本地转发 (http://127.0.0.1:10100/v1)`（带自动连通性检测绿色圆点）；
* **自定义提供商列表**：
  * **OpenCodex / Tuzki**：Base URL + Token
  * **DeepSeek 官方**：Base URL + API Key
  * **OpenAI / Claude 官方**：Base URL + API Key
  * **自定义 OpenAI 兼容接口**：任意三方中转网关。

### 3. 多 Agent 默认模型设置 (Role-to-Model Mapping)
提供直观的下拉选单，为 Beacon 核心四大角色分别指派最适合的底座模型：
* **🛡️ 参谋长 (Chief of Staff)**：默认 `deepseek-chat` / `claude-3-7-sonnet`（高情商意图复述）
* **📐 真相官 (Architect)**：默认 `deepseek-reasoner` / `o3-mini`（严谨冻结逻辑）
* **💻 码农工 (Coder)**：默认 `claude-3-5-sonnet` / `deepseek-chat`（高效代码编写）
* **🔍 质检官 (QA Verifier)**：默认 `gemini-2.5-flash` / `gpt-4o-mini`（低成本高速读日志验资）
