# Beacon Go v3.0.3

Released: 2026-11-25

## What changed

- Seven skill packages renamed to `beacon-go-*`; folder, frontmatter name and
  installed directory now agree.
- Removed the unsupported `triggers` frontmatter field; trigger phrases are in
  each description.
- Added `agents/openai.yaml` for every skill and the generated router.
- Evals migrated to `skill_name` / `evals`, with should-not-trigger cases.
- `plan` adds `pln-brownfield`; `verify` adds `qa-code-review`.
- The kernel does not spawn reviewers. The host fans out and registers the
  aggregate; sequential runs must say so.

- `python3 ~/.codex/skills/.system/skill-creator/scripts/quick_validate.py <skill-dir>`
- `go test ./... -count=1`
- `go vet ./...`

- `bash e2e/run_dogfood.sh`
