# Beacon Go v3.0.4

Released: 2026-11-25

## What changed

- `truth_path` links a feature node to its requirement package. The link is a
  pointer; status synchronization is a read-only report, and freeze/verify
  remain the only status writers.
- `truth node generate-tests` derives planned AC/FSM test skeletons.
- `truth node generate-doc` derives a requirement-document skeleton.
- Both generators default to dry-run; `--apply` writes drafts, and frozen
  nodes require explicit `--change`.
- The HTML tree is collapsible, shows text status badges and a legend, supports
  `status:` filters and expand/collapse-all, and persists collapse state.
