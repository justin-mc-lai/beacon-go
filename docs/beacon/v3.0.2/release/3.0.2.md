# Beacon Go v3.0.2

Released: 2026-11-25

## What changed

- The generated `beacon-go` router skill now describes the 3.x
  requirement-truth kernel instead of a "v2 track". The stale label came from
  the embedded router template.
- No command, ledger, API, or workflow change.

## Verification

- `go test ./... -count=1`
- `go vet ./...`
- `bash e2e/run_e2e.sh`
- `bash e2e/run_dogfood.sh`
- `bash scripts/check_version_consistency.sh`
- Reinstall into `~/.agents/skills` and check the router body.
