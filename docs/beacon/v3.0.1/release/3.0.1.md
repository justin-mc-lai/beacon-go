# Beacon Go v3.0.1

Released: 2026-11-25

## What changed

This patch makes the user-facing surface match the 3.0.0 kernel.

- README (English and Chinese) documents the seven command groups, the tree
  workflow, and the seven embedded skills. Stale v2, desktop, and executor
  sections are removed.
- The `qa` skill is renamed `beacon-go-verify`; its commands use `beacon verify`.
  Stale program/ralph/sea-lake guidance is removed from skill bodies, references,
  and examples.
- `beacon ui` and the `loop` pointer are removed. Internal maintenance commands
  (`spine`, `archive`, `hooks`, `fsm`, `review`, `migrate`, `doctor`) stay
  executable but are hidden from help.
- `implement` and `truth` help text no longer advertise removed executors or a
  package-only truth model.
