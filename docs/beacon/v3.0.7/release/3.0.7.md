# Beacon Go v3.0.7

Released: 2026-11-25

## Added

- `plan init --local-only` sets local-only mode, ignores `.beacon/` and
  `docs/beacon/`, and writes `local_only = true` to `.beacon/config`.
- Default HTML rendering honors the persisted local-only mode.
- Existing tracked docs are reported with the required cache-only removal
  command; the index is never changed implicitly.
