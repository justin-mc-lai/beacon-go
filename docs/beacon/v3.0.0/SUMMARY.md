# v3.0.0 — intent-tree truth kernel

First stable release of the intent-tree kernel.

- Requirement truth is a single tree; sea/lake is retired.
- Kernel is host-driven: no built-in agent executors, no LLM client, no HTTP/desktop surface.
- Seven command groups: plan, truth, change, implement, verify, release, goal.
- Verification is evidence-bound: node scope artifacts, leaf verification, parent rollup.
- History is immutable: frozen fingerprints and version snapshots.

Release notes: [release/3.0.0.md](release/3.0.0.md).
