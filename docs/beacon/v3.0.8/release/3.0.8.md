# Beacon Go v3.0.8

Released: 2026-11-25

## Fixed

- `plan init --local-only` uses the repository-local `.git/info/exclude` for
  `.beacon/` and `docs/beacon/`; it no longer edits the tracked `.gitignore`.
- HTML rendering honors the same local-only boundary.
- Non-git projects fall back to `.gitignore`; existing tracked files are still
  reported with the explicit cache-removal command.

- `go vet ./...`
- `bash e2e/run_e2e.sh`
- `bash e2e/run_dogfood.sh`
- `bash scripts/check_version_consistency.sh`
